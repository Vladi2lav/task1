Как запустить сбор из консоли

В папке проекта, с активированным виртуальным окружением:

Обе биржи за последние {{ history_days }} дней (по умолчанию)
python manage.py collect_trades
Одна биржа за последние N дней
python manage.py collect_trades --exchange ets --days 7
За произвольный период
python manage.py collect_trades --exchange caspy --since 2026-10-01 --until 2026-10-14
Ежедневный сбор по расписанию (процесс работает постоянно)
python manage.py run_scheduler
{% for command in news_commands %}
Сбор новостей
python manage.py {{ command }}
{% endfor %}
