The rights to the original information belong to the exchanges. The Portal is not an official resource of the exchanges; in case of discrepancies, the information on the exchange’s website is considered correct.

2. How the data is collected

  • only public pages and files available to any visitor without registration or signing in are used; technical restrictions of the websites are not bypassed;
  • requests are made sequentially in a single thread, with a pause of {% if http_config.delay_seconds %}{{ http_config.delay_seconds }} s{% else %}at least one second{% endif %} between requests and a limited number of retries on errors;
  • requests carry a clear User-Agent header{% if http_config.user_agent %} ({{ http_config.user_agent }}){% endif %} by which the exchanges’ website administrators can identify the portal;
  • collection runs once a day{% if schedule_config.hour is not None %} (at about {{ schedule_config.hour|stringformat:"02d" }}:{{ schedule_config.minute|default:0|stringformat:"02d" }} Kazakhstan time){% endif %} after the end of trading; only the last few days are reloaded; duplicates are not saved;
  • the information is brought to a single format (dates, numbers, letter case, BIN) without changing its meaning;
  • when pages are opened, the portal does not contact the exchanges’ websites — it shows only the stored database.
