# Итоги торгов бирж ETS и Каспий

Учебный проект (производственная практика, 12 октября — 12 ноября).

Система из двух частей:

- **Парсер** — собирает данные об итогах торгов с сайтов бирж и сохраняет в базу данных.
- **Веб-портал** — показывает собранные данные в таблице с фильтрами, сортировкой и пагинацией.

## Источники данных

- ETS — https://ets.kz/documents/trading-results/
- Каспий — https://ccx.kz/trading-and-analytics/trading-results

## Что умеет проект

- Парсер для каждой биржи, данные приводятся к единому формату
- Защита от дублей: повторный запуск не создаёт повторных записей
- Журнал запусков и ошибок
- Ежедневный запуск по расписанию и ручной запуск
- Портал: таблица, сортировка, пагинация, фильтры без перезагрузки страницы
- Страница состояния данных (последнее обновление, число записей)

## Стек

Python, FastAPI, SQLite, APScheduler, HTML/CSS/JavaScript (стек может измениться).
