# Описание источников

Анализ на 14.10.2026. Публичных API и готовых парсеров на GitHub для обеих бирж найти не удалось.

## ETS — https://ets.kz/documents/trading-results/

Структура сайта: `Итоги торгов` → год (`/2025-god/`, `/itogi-torgov-2026/`) → месяц (`.../itogi-torgov-2026-god-oktyabr/`) → файл за торговый день.
Каждый день — один XLSX (`<a href="/upload/iblock/…/….xlsx" download="07.10.2026 … ИТОГИ ТОРГОВ.xlsx">`). Дата торгов берётся из названия файла/заголовка листа (`ИТОГИ ТОРГОВ 07.10.2026`).
Страницы отдаются в UTF-8, JS для получения ссылок не нужен — достаточно requests + BeautifulSoup.

### Колонки XLSX (лист «07.10», шапка в 3-й строке, данные с 4-й, последняя строка «Итого» пропускается)

| Колонка | Поле в БД |
|---|---|
| B Наименование покупателя | buyer.name |
| C БИН покупателя | buyer.bin |
| D Брокер покупателя | buyer_broker |
| E Наименование продавца | seller.name |
| F БИН продавца | seller.bin |
| G Брокер продавца | seller_broker |
| H Наименование товара (каз/рус через `/`) | product.name |
| I Код ТН ВЭД ЕАЭС | product.tnved |
| J Код товара | product.code |
| K Количество заключённых сделок | deals_count |
| L Цена открытия | price_open |
| M Цена закрытия | price_close |
| N Максимальная цена | price_max |
| O Минимальная цена | price_min |
| P Средневзвешенная цена | price_avg |
| Q Общая сумма сделки (тг) | amount |

Нет в источнике: объём, единица измерения, базис/срок поставки (базис иногда зашит в название товара: `EXW`), время торгов, цена с/без НДС.
Строки — агрегат «покупатель + продавец + товар» за день.

### Особенности файлов ETS (выявлены при загрузке реальных данных)

- **История на сайте начинается с июля 2025**; раньше разделов нет.
- **Шапка отличается по файлам.** В 2026 — двуязычная («Сатып алушының атауы/ Наименование покупателя»), местами сокращённая («Кол-во сделок», «Макс. цена», «Средневзв. цена»), с переносами строк. Колонки поэтому определяются по тексту шапки, а не по номерам. Шапка может быть в 4-й и 6-й строке.
- **В файлах 2025 года нет** БИН, брокеров, кода ТН ВЭД и суммы сделки (только участники, товар, код, число сделок и цены). Для них соответствующие поля остаются пустыми, `amount = NULL`.
- **Название и ТН ВЭД товара — формулы `=VLOOKUP(J5,Товар,2,FALSE)`** по скрытому листу «Лист1» (справочник «код → название, ТН ВЭД»). Читаются сохранённые значения формул, при их отсутствии — берутся из справочника по коду товара.
- В названии товара казахская часть идёт латиницей (транслит) и может содержать собственные слэши («t/j»), а русская — «ж/д». Русская часть отделяется по слэшу, после которого начинается кириллица. В справочнике ETS длинные названия местами обрезаны самим источником (на «поставка только ж/д» → «поставка тольк»).
- Базис поставки (EXW, FCA и др.) в источнике не отдельная колонка, а конец названия товара; он дополнительно записывается в `delivery_basis`.
- Название листа бывает «07.10», «14.07.2026», «26082026», «Лист1 » — по нему дату определять нельзя. Заголовок листа иногда устаревший (в файлах за октябрь 2025 везде «20.08.2025»), поэтому дата торгов берётся из названия файла (атрибут `download`), а заголовок листа — запасной вариант.

## Каспий — https://ccx.kz/trading-and-analytics/trading-results

Страница итогов торгов на сайте при любых фильтрах показывает «Нет данных для отображения» (проверено и из тестовой среды, и из браузера пользователя 14.10.2026). Реально данные отдаёт только внутренний JSON, которым пользуется сайт:

`GET /api/internal/trading-results?section_code=CL&instrument_regulated=true|false&max_results=20`

- Возвращает **только последние 20 лотов** по секции и режиму торгов (регулируемые / спот). Любое значение `max_results`, кроме 20, даёт пустой список; параметры дат и страниц игнорируются. Истории сайт не отдаёт, она накапливается ежедневными запусками.
- Коды секций: `CL` — уголь (данные есть), `OIL` — ГСМ и `CM` — цемент (пока пусто, парсер их опрашивает на случай появления данных).
- Участников сделок и брокеров биржа не публикует; запись — итог по лоту за день.

Поля ответа и их соответствие единому формату:

| Поле API | Поле в БД |
|---|---|
| day_of_trade | trade_date |
| lot_code / lot_name | product.code / product.name |
| delivery_term (EXW, FCA, DDP) | delivery_basis |
| basis (станция, область) | delivery_place |
| deal_count | deals_count |
| volume_deals («6 300 тонна») | quantity + unit |
| avg_price_deals + vat («с НДС» / «без НДС») | price_avg и price_with_vat / price_without_vat |
| sum_deals | amount |

Не используются: цены спроса и предложения (min/max ask/bid), базовая цена, объёмы заявок.
